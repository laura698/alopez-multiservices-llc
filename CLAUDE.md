# Julio Cash Electronic

## Proyecto
Landing/ecommerce de electrodomésticos desplegado en Vercel.

## Reglas
- Mantener el diseño responsive.
- No modificar funcionalidades no relacionadas con la tarea.
- No instalar dependencias sin necesidad.
- Reutilizar componentes existentes antes de crear nuevos.
- Mantener Tailwind como sistema de estilos.
- No modificar vercel.json salvo que sea imprescindible.
- Antes de hacer cambios importantes, explicar brevemente el plan.
- Después de modificar código, ejecutar las validaciones disponibles.
- No hacer push a main sin mi autorización.

## Git
- Hacer cambios pequeños y fáciles de revisar.
- No usar force push.
- No borrar archivos sin autorización.

## Optimización de contexto
- Leer solamente los archivos necesarios para la tarea.
- No analizar todo el repositorio cuando la tarea afecta un componente concreto.
